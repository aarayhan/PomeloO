# Security

Only the latest release gets fixes (PomeloO updates itself).

Found a vulnerability? Please report it privately: open an advisory at
https://github.com/aarayhan/PomeloO/security/advisories/new instead of a public issue.
Include the version, what you did and what happened. Expect a reply within a few days.

PomeloO processes files locally and never uploads them; the only network use is the update check
(GitHub), the optional one-time LibreOffice download and phone transfer on your own network.
