# Contributing

Bug reports, ideas and pull requests are welcome. PomeloO is licensed AGPL-3.0, and contributions are
under the same license.

- Open an issue first for anything bigger than a small fix.
- Run it from source: see "Build from source" in the [README](README.md).
- Before a pull request, run `.venv\Scripts\python.exe tests	est_convert.py`; it converts every pair and runs every tool.
- Keep changes small and match the style of the code around them.
